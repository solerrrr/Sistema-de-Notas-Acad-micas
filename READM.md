
# Painel de Notas do Aluno

## 1. Nome e tema do projeto

O projeto se chama Painel de Notas do Aluno e tem como tema
o acompanhamento do desempenho academico.

## 2. Explicacao da interface

A interface apresenta uma tela visual de login e um painel
demonstrativo com informacoes do aluno, media geral,
quantidade de disciplinas e notas por materia.

O login e demonstrativo e nao realiza autenticacao real.
As notas exibidas na interface sao ficticias.

## 3. Componentes Bootstrap utilizados

- Navbar: barra de navegacao.
- Container: organiza e centraliza o conteudo.
- Row e Col: organizam os elementos em colunas responsivas.
- Card: apresenta informacoes e notas.
- Badge: identifica situacoes academicas.
- Button: apresenta o botao de acesso.
- Alert: exibe um aviso.
- Footer: apresenta o rodape.

O Bootstrap foi carregado por meio de CDN, sem arquivo CSS proprio.

## 4. Diferenca entre const, let e var

- const: utilizada quando nao pretendo reatribuir o valor
  de uma variavel.
- let: utilizada quando preciso permitir a alteracao do valor.
- var: declaracao mais antiga, demonstrada para fins de estudo.

A pratica atual prioriza const e let porque possuem escopo
mais previsivel e ajudam a evitar alguns erros.

## 5. Tipos de dados utilizados

- String: nome do aluno e nome da disciplina.
- Number: notas, medias e quantidade de disciplinas.
- Boolean: indica se a matricula esta ativa.
- Null: representa a ausencia intencional de um valor.

## 6. Condicao if/else

A condicao compara a media do aluno com a nota minima 6.

Se a media for maior ou igual a 6, o resultado sera
"Aprovado". Caso contrario, sera "Precisa recuperar".

O resultado pode ser testado alterando os valores das notas.

## 9. Como executar o projeto

1. Baixe ou clone o repositorio.
2. Abra o arquivo index.html no navegador.
3. Pressione F12 para abrir as ferramentas do desenvolvedor.
